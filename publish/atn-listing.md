## Name

heron

## Summary (250 characters max)

**fr**: Un Thunderbird calme, inspiré d'Apple Mail : conversations empilées, balayage, recherche unique, pas d'onglets, annuler l'envoi. Chaque fonction s'active séparément. Aucune donnée ne quitte votre ordinateur.

**en**: A calm Thunderbird, inspired by Apple Mail: stacked conversations, swipe actions, one search field, no tabs, undo send. Every feature can be turned on or off. No data ever leaves your computer.

## Description

**en**

heron reshapes Thunderbird's interface to feel calm and reassuring. Every feature below is a separate module that you can turn off in heron's options; changes apply immediately, without a restart. Disabling or removing heron restores Thunderbird exactly as it was.

Appearance
- Quieter interface: more space, softer warnings, cards with rounded corners.
- Changes these Thunderbird settings while heron is active (your previous values are restored when the module or heron is turned off): interface density, text size (a multiple of your system's size, adjustable), sender display (name only, the real domain is shown next to it), message list card height, dark message content when the system is dark.

Message list
- Friendly dates using Thunderbird's own wording ("yesterday", "Monday"…).
- The sender's real domain next to the name, in red when the name imitates a known brand or contains another address (phishing hint). Text preview under the subject, computed by Thunderbird for messages already on your computer (nothing is downloaded for a preview).
- One row per conversation, with participants and message count.

Reading
- Conversations shown as a stack of cards, including your replies stored in Sent; click a card to expand or collapse it; order is adjustable.
- Quoted history and signatures folded behind a "•••" button (nothing is deleted).
- Tracking pixels reported in the message header ("2 trackers blocked"). heron only looks at the message: it never loads or blocks anything itself; Thunderbird's remote content setting decides.

Actions
- Swipe a message card left or right (trackpad) to delete, archive, mark read, flag or mark as junk, with Undo. Configurable.
- Undo send: when you click Send, the message waits in the Outbox for a few seconds (10 by default, adjustable, 0 turns it off) with an "Undo" button, then is sent. If heron is turned off during the delay, the message is sent right away.

Search and navigation
- One search field for everything: the top search field filters the current folder or all folders (no results tab), understands keywords (from:, to:, subject:, before:, after:, in:, has attachment…) and offers an advanced filter panel. It also filters the calendar, tasks and contacts. Thunderbird's Quick Filter bar is hidden because the top field replaces it.
- No tabs: the tab bar is hidden; Settings, Add-ons and messages opened on their own appear as a floating card above the mail (close with ✕, Escape or a click outside). "Open in new tab" menu items are hidden.
- Unified folders (All Inboxes, All Sent…) shown first when you have at least two mail accounts, added once; you can remove them in Thunderbird as usual.

Writing
- Calmer compose window: Send stands out, Attach is next to it, the formatting toolbar is behind an "Aa" button. The saved toolbar layout is not changed.

Removing heron: disabling or uninstalling heron restores every Thunderbird setting it changed. In "If I remove heron…", you can choose to keep the roomier interface, the text size or the unified folders; they then become your own settings. Senders' full addresses are always restored.

If a module fails after a Thunderbird update, heron turns it off for that version and says so in its options; Thunderbird keeps working normally.

**fr**

heron rend l'interface de Thunderbird calme et rassurante. Chaque fonction ci-dessous est un module qu'on peut désactiver dans les options de heron ; le changement s'applique tout de suite, sans redémarrer. Désactiver ou supprimer heron rend Thunderbird exactement tel qu'il était.

Apparence
- Interface plus calme : plus d'air, avertissements adoucis, cartes aux coins arrondis.
- Modifie ces réglages de Thunderbird tant que heron est actif (vos valeurs d'avant reviennent quand on désactive le module ou heron) : densité de l'interface, taille du texte (un multiple de celle du système, réglable), affichage de l'expéditeur (le nom seul, le vrai domaine est affiché à côté), hauteur des cartes de la liste, contenu des messages en sombre quand le système est sombre.

Liste des messages
- Dates amicales, avec les mots de Thunderbird (« hier », « lundi »…).
- Le vrai domaine de l'expéditeur à côté du nom, en rouge quand le nom imite une marque connue ou contient une autre adresse (indice d'hameçonnage). Aperçu du texte sous l'objet, calculé par Thunderbird pour les messages déjà sur l'ordinateur (rien n'est téléchargé pour un aperçu).
- Une ligne par conversation, avec les participants et le nombre de messages.

Lecture
- Conversations en pile de cartes, y compris vos réponses rangées dans Envoyés ; un clic déplie ou replie une carte ; ordre réglable.
- Historique cité et signatures repliés derrière un bouton « ••• » (rien n'est supprimé).
- Pixels de pistage signalés dans l'en-tête (« 2 traqueurs bloqués »). heron ne fait que regarder le message : il ne charge ni ne bloque rien lui-même ; c'est le réglage de contenu distant de Thunderbird qui décide.

Actions
- Balayer une carte vers la gauche ou la droite (pavé tactile) pour supprimer, archiver, marquer comme lu, suivre ou indésirable, avec Annuler. Configurable.
- Annuler l'envoi : après Envoyer, le message attend quelques secondes dans la boîte d'envoi (10 par défaut, réglable, 0 désactive) avec un bouton « Annuler », puis part. Si heron est désactivé pendant le délai, le message part aussitôt.

Recherche et navigation
- Un seul champ de recherche : le champ du haut filtre le dossier courant ou tous les dossiers (sans onglet de résultats), comprend des mots-clés (de:, à:, objet:, avant:, après:, dossier:, pj…) et propose un panneau de filtres avancés. Il filtre aussi l'agenda, les tâches et les contacts. La barre de filtre rapide de Thunderbird est masquée : le champ du haut la remplace.
- Pas d'onglets : la barre d'onglets est masquée ; Paramètres, Modules complémentaires et messages ouverts seuls s'affichent en carte flottante au-dessus du courrier (fermer : ✕, Échap ou clic à côté). Les entrées « Ouvrir dans un nouvel onglet » sont masquées.
- Dossiers unifiés (Toutes les boîtes de réception, Tous les envois…) en tête quand vous avez au moins deux comptes de courrier, ajoutés une seule fois ; on peut les retirer comme d'habitude.

Rédaction
- Fenêtre de rédaction plus calme : Envoyer ressort, Joindre est à côté, la barre de mise en forme est derrière un bouton « Aa ». La disposition enregistrée de la barre d'outils n'est pas modifiée.

Retirer heron : le désactiver ou le supprimer rétablit chaque réglage de Thunderbird qu'il avait changé. Dans « Si je retire heron… », on peut choisir de garder l'interface aérée, la taille du texte ou les dossiers unifiés ; ils deviennent alors vos propres réglages. L'adresse complète des expéditeurs est toujours rétablie.

Si un module échoue après une mise à jour de Thunderbird, heron le désactive pour cette version et le signale dans ses options ; Thunderbird continue de fonctionner normalement.

## Privacy policy (full text)

**en**

heron does not collect, store remotely, or transmit any data. It makes no network requests, uses no analytics, no cookies, and contacts no server, including its developer's. Everything heron reads (messages, folders, contacts for search suggestions, the search index) stays inside Thunderbird on your computer and is used only to display the features described above. heron's settings are kept in Thunderbird's local extension storage and preferences, and are removed or restored when heron is uninstalled. The manifest declares that no data is collected.

**fr**

heron ne collecte, ne stocke à distance et ne transmet aucune donnée. Il ne fait aucune requête réseau, n'utilise ni statistiques, ni témoins (cookies), et ne contacte aucun serveur, y compris celui de son développeur. Tout ce que heron lit (messages, dossiers, contacts pour les suggestions de recherche, index de recherche) reste dans Thunderbird, sur votre ordinateur, et ne sert qu'à afficher les fonctions décrites ci-dessus. Les réglages de heron sont gardés dans le stockage local des extensions et les préférences de Thunderbird, et sont retirés ou restaurés à la désinstallation. Le manifeste déclare qu'aucune donnée n'est collectée.

## Note to reviewers (in English)

heron changes how Thunderbird's main window works (message list rendering, reading pane, search field, tab bar, compose toolbar). None of this is reachable through the MailExtension APIs, so heron uses one Experiment, `heron` (api/implementation.js). Where a built-in API exists, it is used: quoted text folding runs through `messageDisplayScripts` (background.js); settings use `storage`; the options page is a regular `options_ui` page.

How the Experiment works
- Control: background.js reads settings from `storage.local` and passes them to the Experiment (`init`, `setConfig`). The Experiment exposes only `init`, `setConfig`, `getStatus` and `clearFailures` (api/schema.json).
- Code loading: the Experiment registers the add-on's own files as `chrome://heron/content/` and loads each module with `Services.scriptloader.loadSubScript` into a sandbox whose prototype is the target window. No string evaluation, no remote code, no minified or generated code: every file in the XPI is the human-readable source. Styles are the add-on's CSS files, registered as user sheets scoped with `@-moz-document` to Thunderbird's own pages (never message content or web pages).
- Clean shutdown: every module installs its listeners, wrappers and elements through content/prelude.js, which records how to undo them. On disable, uninstall or update (`onShutdown`), heron restores every preference it changed (their original values are saved in `extensions.heron.savedPrefs`), stops every module, removes its style sheets, unregisters its chrome registration and invalidates the startup cache. Only settings the user explicitly chose to keep in the options ("If I remove heron…": density, text size, unified folders) are left as they are. Turning a module off in the options applies immediately the same way.
- Safety: a module that throws at startup is disabled for that Thunderbird version only, and the options page says so; Thunderbird keeps its normal behaviour.
- Data: no network access at all (the only `fetch` reads the add-on's own `_locales` file). `data_collection_permissions` is `none`.
- Undo send holds an outgoing message in the Outbox for a few seconds (Thunderbird's own "Send Later" mechanism) and then sends it with `nsIMsgSendLater`; if heron is turned off during the delay, held messages are sent immediately, so nothing is left in the Outbox.

Testing: no account or credentials are needed; any local folder with a few messages works. Open heron's options to turn features on and off.
